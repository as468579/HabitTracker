# HabitTracker — 使用說明

設定每日、每週、每月任務，用總覽、活躍方格與日曆追蹤完成情況。支援 iPhone 加入主畫面（PWA）。

[開啟 HabitTracker](https://habittracker.beneficiallapwing1.chatgpt.site/)

網站目前僅限擁有者帳號，請登入與建立網站時相同的 ChatGPT 帳號。

## 在 iPhone 安裝

1. 用 Safari 或 Chrome 開啟正式網站，登入與建立網站時相同的 ChatGPT 帳號。
2. 點「分享」→「加入主畫面」。
3. 若有「以網頁 App 開啟」選項，保持開啟，按「新增」。
4. 回到 iPhone 主畫面，點「HabitTracker」圖示使用。

這是 PWA，不需從 App Store 下載。若從 LINE 連結開啟，請先複製網址到 Safari 或 Chrome。安裝後若再次要求登入，請使用相同帳號。

## 開始設定任務

首次登入的雲端任務清單為空白，不會預載範例。手機與電腦請登入相同 ChatGPT 帳號。

按「新增任務」，輸入名稱，選擇每日／每週／每月、生活分類及備註，再儲存。點任務前的方框即可標記或取消完成；點編輯圖示可修改或刪除任務。

每週由星期一開始，每月由一日開始。每天、每週或每月的新週期各自計算完成狀態。

## 查看總覽與日曆

總覽的每日／每週／每月分別統計對應頻率的任務。使用日期箭頭可查看歷史週期。

年度活躍圖每格代表一天，顏色深淺表示每日任務完成比例。Daily Routine 日曆可選日期查看當日任務，並補登歷史紀錄；未來日期不能勾選。

當天所有每日任務都完成才算達標。每週與每月任務不計入每日活躍圖或每日連續達標；沒有安排每日任務的日期不計入日曆達標分母。

## 調整字體與模式

進入「設定 → 外觀設定」，選擇標準 100%、較大 115% 或最大 130% 字體，以及 Bright／Night 模式。選取後立即套用並保存在目前裝置。右上角太陽／月亮按鈕也能切換模式。

## 使用記帳室

在「記帳室」進入或離開聊天室，對話保存在遠端資料庫並依帳號同步。可輸入「午餐 120，咖啡 65」等文字，或用手動新增記錄品項、金額、日期與分類，預設幣別為新台幣。

目前 OpenClaw 尚未安裝與連線。聊天訊息只會保存為待處理，不會自動轉成消費紀錄；待處理訊息不計入支出統計。手動新增的消費才會列入帳本。

## 離線、更新與資料保存

安裝後可離線開啟 App 框架；雲端資料的讀取與修改需要網路。若儲存失敗或資料已由其他裝置修改，會顯示提示，請重新同步並確認內容後重試。只有遠端資料庫確認成功後才會顯示已儲存。

看到新版本提示時，點「重新載入更新」。一般更新不會清除雲端個人紀錄。

任務、完成紀錄、消費明細與聊天訊息保存在遠端 Cloudflare D1 資料庫，依登入帳號隔離。相同帳號在手機與電腦可同步；連線時每 10 秒及回到 App 時重新整理。外觀偏好仍保存在各裝置。舊版瀏覽器本機紀錄不會自動匯入，避免重新帶入已要求清除的範例資料。

「清除所有任務資料」會刪除雲端任務與完成紀錄，並反映到其他裝置，無法復原；不會一併刪除記帳室資料。
