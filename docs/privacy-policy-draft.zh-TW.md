# HabitTracker 隱私權政策草稿

更新日期：2026-11-18。這是網站目前行為的文件草稿；原生商店上架前需重新確認實際產物與發行者資訊。

- 使用 ChatGPT 帳號登入，Sites 提供使用者識別碼用於資料隔離。
- 任務、完成紀錄、聊天及消費資料透過 HTTPS 傳輸並儲存在 Cloudflare D1，供同一帳號跨裝置同步。
- 字體大小與 Bright/Night 偏好保存在目前裝置。
- 設定中清除任務會清除雲端任務與完成紀錄，並同步其他裝置；不會清除記帳室資料。
- 清除瀏覽器資料不會刪除雲端紀錄。平台備份或復原機制可能保留歷史資料，App 不提供使用者自行復原。
- OpenClaw 仍未安裝與設定；訊息只會保存為待處理，不會自動送往外部 agent。
- 未整合廣告或使用者追蹤服務。

網站正式政策位於 src/app/privacy.tsx，後續新增資料用途、服務或原生 App 時應同步更新。
