# 共用介面樣式

樣式來源為 `src/theme.ts`，所有畫面與表單透過 `src/Appearance.tsx` 的 `useThemedStyles` 共用動態 `theme` 與 `ui`。延伸現有樣式時，先使用共用規格，再補各元件必要的布局。

- Bright 使用中性淺色，Night 使用深綠灰底；卡片隨模式套用表面與邊框色，維持 1px 邊框、16px 圓角、24px 內距。
- 右上角日／月圖示可切換模式，偏好儲存在目前裝置。圖表、表單、彈窗與隱私頁同步切換。
- 設定的「外觀設定」提供 Bright／Night 模式及標準（100%）、較大（115%）、最大（130%）字體。字級與行高透過 `theme.textScale` 同步縮放；新增文字樣式請沿用 `ui` 或使用 `theme.font`。
- 主要色：綠色 `#377A57`，用於主按鈕、完成狀態、選取與進度。
- 字級：頁面標題 32px、區塊標題 16px、內文 14px、控制標籤 13px、輔助資訊 12px、密集資訊 11px。手機頁面標題可縮至 29px，圖表依密度調整標籤。
- 主操作及輸入框：至少 44px 高、10px 圓角。次要小型控制可用 36px 高。彈窗：20px 圓角、24px 內距。
- 完成、未完成、警示及分類可使用不同色彩，但必須有圖例、標籤或其他提示，不能只靠顏色。
- 方格活躍圖沿用相同卡片，使用同一綠色系的強度梯度。
- 同一層級的標題與按鈕沿用相同字重和間距；不要以裝飾文案填補留白。

任務、記帳與隱私資料的行為不由此樣式檔控制。
